About

      

        OotleSwap is a constant-product AMM (Uniswap V2 style) on the Tari Ootle
        Layer 2 network. It pairs an on-chain SOON test token against native
        tTARI (revealed sub-balance only — confidential commitments are
        rejected at every entry point so reserves stay in sync).
      

      

        A factory + permissionless registry indexes pools by canonical resource
        pair. Anyone can deploy more pools and register them. Source, tests,
        runbook, and CLI demo binary at
        github.com/MrMooning/Soon-Swap.
