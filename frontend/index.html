How to use this DEX

  1. Run a Tari wallet daemon. Grab tari_ootle_walletd v0.30+ from the tari-ootle releases page. Linux/macOS prebuilts work directly; Windows users run via WSL2. Wallet UI lives at http://127.0.0.1:5100.
  2. Faucet some tTARI. Create an account in the wallet UI, click the faucet — you get 1000 tTARI.
  3. Find your account's component address. On your account detail page, copy the field starting with component_ (64 hex chars). This is your account global — NOT the otl_esm_... form.
  4. Optional: claim free $SOON from the SoonToken faucet — use the manifest below. No tTARI required. Lets you also test selling SOON for tTARI.
  5. Use the swap calculator further down. Type an amount, copy the generated manifest, paste it into your wallet's Manifest tab with the listed globals, set fee to 50000, and submit.

Get free $SOON to test with

The SoonToken component has a public faucet that drips 100 SOON per call. Useful if you want to test the SOON → tTARI direction without buying SOON first.

About

      

        OotleSwap is a constant-product AMM (Uniswap V2 style) on the Tari Ootle
        Layer 2 network. It pairs an on-chain SOON test token against native
        tTARI (revealed sub-balance only — confidential commitments are
        rejected at every entry point so reserves stay in sync).
      

      

        A factory + permissionless registry indexes pools by canonical resource
        pair. Anyone can deploy more pools and register them. Source, tests,
        runbook, and CLI demo binary at
        github.com/MrMooning/Soon-Swap.
